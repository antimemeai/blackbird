# Consolidate raw emission before finishing remaining surfaces

Operator2026-10-13: eliminate repeated emission machinery and wrap the authorized
surface work; stop before workload qualification. Actual RawCallerTrace,
RawProgramCall, RawBeadsTrace, RawBridgeTrace, File Helper and Session implementations
show repeated capacity admission, linked publication, terminal bank ownership and
C++ exception classification. Existing raw_emit/channel/recorder remain shared.

One owned RawEmission in raw_caller.hpp/cpp supplies checked record size, actual
errno-preserving publication with existing failure/fence behavior, linked native
publication, request reference and one held CONTROL bank. start receives literal
request fields, request/end sites, declared whole bank bytes and wait/finite
admission choice. It performs no field projection, Value visits, formatting,
encoding or dynamic dispatch. Owners supply native fields unchanged. close emits
owner-supplied terminal fields linked to its actual request and releases the bank
once. Shared common terminal emission builds the existing branch/stage/Error
layout. Shared compile-time raw_call_run performs existing C++ exception
classification; it invokes the owner's finish directly, without a callback registry
or new runtime state. Preserve references and value returns.

RawCallerTrace becomes the synchronous public convenience adapter. RawSessionCall
continues to wrap it for explicit failure-origin propagation. RawProgramCall keeps
only its method/generation/native revision semantics over RawEmission. Beads keeps
its actual native status, variant-specific fields and business linkage over the
same emission owner. Bridge keeps protected Lua/reentry and suspended token lifetime
handling, using RawEmission for publication/bank/request/terminal mechanics. File
keeps its filesystem exception variant, actual syscall/resource semantics and
wire layout, using the shared publication and owner machinery. UI uses shared
publication where it already immediately emits, retaining its actual frame/worker
banks. Dedicated serialized issuer holders remain only for lifetimes that really
cross threads/bindings; no new per-surface transport, producer per event, registry,
timer, lock or heap allocation is introduced.

Compatibility requirement: existing event sites, field order/width, admission
sizes, null-context opt-out, native errno, cancellation, failure origin, cleanup
funding, coroutine yieldability and parent references stay unchanged. A common
helper cannot silently impose one surface's error or terminal schema on another.
Keep custom lifetime end decisions at their actual owners. Existing direct native
fixtures are the migration oracles; do not create tests that only certify helpers.

One concrete plan attack before edits; resolve valid findings in this plan. Then
migrate within the existing owner lanes, run affected real direct fixtures, and
include consolidation in the source review/gate once. Do not add another review
panel to each settled surface. Subsequent surfaces use the shared machinery.
Root owns shared machinery/CMake; Program lane owns Program/Bridge adapters;
File lane owns Beads/File; UI lane owns UI/Station integration. Root preserves
Main/session ownership and completes its existing finite review findings and
restart/recovery/backstop paths. Keep one shared Ninja writer and at most six
aggregate compiler/static workers. No workload/performance qualification.

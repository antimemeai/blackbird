# Blackbird against the agent corpus, 2026-10-19

Short, question-driven comparisons. Each question reads the source of a few
references that actually answer it, sets that against Blackbird as it is today, and
records what is worth keeping. The heavy 23-axis study in
[`papers/capabilities/`](../capabilities/README.md) (2026-10-01) is not extended
here.

"Blackbird today" means `master` unless a note says otherwise. Reference claims
come from snapshots under `quarantine/`, mostly taken 2026-09-30. Where current
upstream documentation was checked, the note says so. Agents that are missing from
the corpus are tracked in [corpus gaps](gaps.md).

# Native instrument and design challenge

Staff source study and one bounded draft-design challenge,2026-10-16. No product
implementation or qualification claimed. Existing command center and inspector
remain the currently delivered applications.

Use /instrument and otherwise unused Ctrl-] byte29 after privatePTY/paste handling.
Preserve the sole Composer and make jobs/center/instrument mutually exclusive,
retaining each route's native selection and reading state. Enter stays local detail
focus. Specify distinct named pin-A/pin-B/request-interrupt actions before coding.

Reuse one CollectionInspector: actual command IDs in the catalog and a combined
A/B detail with finite pinned4096-byte/16-source windows. Pins retain their bytes,
frontiers and source spans through refresh. Live producer status is separate.
Settled/failed results stay inspectable; interruption is unavailable when no live
producer is actually eligible. Never infer a nearby live job or silently rerun.

SceneHost scene revision changes only on publication. Native selection/focus does
not advance it. Introduce independent local input/query/source generations for
async adoption; scene revision alone cannot reject selectionA's late result after
selectionB. Lua has no Composer draft-write API in the initial slice.

Load ordinary authored source off the input/paint path. Reload/preview must show
effective/pending/failed source distinctly; preview has no effects or effective
handler activation. Preparation precedes successful adoption and actual VM
quiescence precedes replacement. Native file reads are not instruction-preemptible;
a VM worker alone cannot contain arbitrary blocking native extensions.

ApplicationConnection is a separate trusted host/session mode with synchronous
packet writes and one replacement. Its IDs correlate; they do not deduplicate or
reconcile uncertain actions. Reuse existing pure owner observations for composition
and actual process control ownership for effects, rather than calling application
pump a UI mailbox. Internal adapters continue to use native values, never JSON.

Capture exact loaded source/file-read origin, immutable finite inputs and literal
native candidate/action descriptors at distinct raw sites. Adoption/refusal names
them and actual4010 input origin, using exact nonblocking DATA/CONTROL admission.
Refusal preserves last-good native scene and visibly stale status. Center4088/4089
formats remain unchanged.

First domain action: Request interrupt(SIGINT) for the frozen selected live job,
using existing process op=signal/signal=interrupt/request_id reservation. Current
Delivery.done means worker consumption, not proven kill success or application
handling. Add pure bounded receipt observation; never invoke control as a query.
Actual operation/raw references require owner-issued handoff, not guessed indices.
Accepted action envelopes/receipts outlive Lua view/reload; missing acknowledgement
is inspected by original key or remains unknown, with no automatic resubmission.

Direct semantic REDs precede implementation: phase rejection before admission;
selection/query/source retirement versus late candidate; normal/nested-pcall loop,
error/OOM and native-control progress; withheld acknowledgement plus reload;
changed-key arguments conflict, distinct deliberate triggers; exact target exit.
Microsoft Ghostty+Alacritty and readable wide/narrow expectations separately test
presentation. Actual blocked stdout tests native controls independently of display.
Do not label this slice completion of every Unit2 contract or future view owner.

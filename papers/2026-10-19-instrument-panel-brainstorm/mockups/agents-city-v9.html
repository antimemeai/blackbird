Subagents v9: dark city tuning

The floor is the code as a city: directories are zones, files are districts, functions are blocks sized by lines of code.

The city remembers. Every touch warms a block in the toucher's team color, and the warmth fades over about a minute. Edits raise the block permanently, so tall blocks are where the session's churn went.

Agents hover above their block on a drop-line. Altitude = context fill: an agent climbs as it approaches compaction. Its label rides with it.

Motion follows structure: agents glide between functions in the same file and arc only when they jump to another file.

Events have shapes: an edit beams down and ripples, a test run pulses across tests/, a failure flares red, and a read is a faint blink.

Tuning (after Dark City): when an agent adds or removes a function, the treemap re-lays out and every building slides and stretches into its new lot. New functions telescope out of the street and removed ones sink. Edits telescope blocks upward with a little overshoot.

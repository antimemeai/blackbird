Subagents: the "crossing" skeleton, two Blackbird mappings

Both keep the skeleton: two planes in perspective, agents as glyphs clustered where they work, a crossing between planes, trajectories (loops = going around again), and callout pills pinned to events. The camera drifts slowly so the depth reads. Glyph shape = model family (● gpt · ▲ claude · ■ kimi · ◆ jev-driven), color = the agent's team color. The data is fake.

A · The crossing: planned → landed

Back plane = the work as planned: one cluster per epic, small squares are its beads, and agents sit on the bead they've claimed. The conduit is the qualification path (rigor check, tests, review). Changes ride it toward the front plane = landed work (pushed commits, closed beads). A failed check throws the change back out in a loop. Callouts mark gate events.

B · Codebase × time

Each plane is the repo map (directories as regions). The front plane is now and fainter planes behind it are earlier, so depth = time. Each agent leaves a trail through the files it read or wrote over time. Its glyph sits on the "now" plane with a pill showing its last action and tokens. Two agents converging on the same file get flagged.

Hero: which waterfall?

Both use the same fake session, sped up about 20×. Each lane is a colleague or subagent, and Jev runs on the far right. In both, one pixel or particle is a fixed number of tokens, so how dense or wide the stream looks is the measurement. Watch sa·fuzz: its stream dries up partway through.

A · Spectrogram waterfall

This works like a radio waterfall. Every 100 ms a new row of pixels appears at the top and everything scrolls down. In each lane, the number of lit pixels in a row is the token rate (1 px = 250 tok/s), laid out as colored bands by token class. Bursts read as bright bands and silence as black. The last 90 seconds stay on screen as texture.

B · Particle cascade

As tokens arrive, each lane pours out particles (1 particle = 1k tokens), colored by class. The particles fall and pile up at the bottom, so each pile's height is that lane's cumulative total. Live flow shows at the top and the running totals at the bottom. It's closest to the look of the video.

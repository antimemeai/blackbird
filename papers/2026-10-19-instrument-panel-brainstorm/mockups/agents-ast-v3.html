Subagents v3: AST corner

Back wall (XY) = a coarse AST of the code: directories → files → classes and functions, drawn as a tidy tree. Agents sit on the node they're touching right now.

Depth (Z) = time. Each agent's trail runs back from "now" through where it has been.

Floor (XZ): the trail's shadow, meaning which branch of the tree over time, so you see agents moving to and fro across the codebase.
Side wall (YZ): the other shadow, meaning tree depth over time, so you see dives from file level down into functions and back out.

Right column: last action, node and tokens per agent. A red ring means two agents are on the same subtree and one is editing. Fake data.

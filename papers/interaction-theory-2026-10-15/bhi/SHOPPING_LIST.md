# BHI evidence gaps

2026-10-15. No selected original is blocked. Three new paper PDFs and their
official metadata pages were retained, with the existing SWE-agent v3 PDF reused.

These are questions for later source selection, not dependencies of the written
theory and not an implementation or evaluation plan:

- Primary evidence for current configured models using Lua programs versus atomic
  tool calls, including partial failures and observation-dependent branching.
  CodeAct tests Python and historical models; it cannot settle this transfer.
- Systematic human/model collaboration evidence for steering several live
  colleagues through shared operation and artifact identities. ReAct's thought-
  editing example is insufficient, and private reasoning visibility is not assumed.
- Evidence on continuity after model-editable context repair, live program
  replacement and executable refit. Long-context QA measures information use,
  not preservation of the harness's external obligations or continuations.
- Evidence on useful observation detail when a model must detect a misleading
  summary or an unknown external effect. Concise defaults alone do not establish
  when a model will notice that it needs to recover originals.

No paid access, account action, hardware purchase or operator download is currently
required by this lane. Newly selected sources should be acquired only if they bear
on a live theory/design question, with originals and restoration recorded.

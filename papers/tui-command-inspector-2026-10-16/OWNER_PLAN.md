# Pure command observation subplan

Root authorizes one whole owner unit after the source study: fixed native public
query/result values, allocation-free noexcept try_observe, genuine current-command
identity/state and bounded retained source bytes. Parent owns renderer/navigation,
try-prepaid raw UI apply publication and final source-gate integration.

Build a checked fixed32-byte CommandObservationId, optional fixed continuation and
selected IDs; query budgets catalog rows<=8, one independent selected detail (<=9 metadata
projections total), bytes<=4096, chunks<=16 and byte offset.
Return explicit Ready/Busy/InvalidIdentity/InvalidRange/Unavailable; selection is
NotRequested/Resident/NotResident. Row state is actual lifecycle/custody plus the
independent flags/frontiers/known-exit values. Fixed byte/source arrays own all
cross-owner data. Source extents carry actual read Ref, logical chunk beginning,
within-original offset and length. No Value/JSON, dynamic allocation, raw emission,
blocking lock, engine/journal scan or UI-domain effect enters this method.

Before production implementation, add the permanent oracle and show the genuine
old Value read under allocation refusal fails the required ready bounded query;
keep that old-path adapter only in ignored RED source. A missing new symbol is not
RED. Then implement transparent-key lookup, one try_lock, bounded catalog prefix,
selected metadata and deque binary seek plus finite copy. Work/budget termination
is part of returned query coverage, not a producer metric stream.

Permanent checks use actual child output and owner acknowledgments, immutable
copied pages, malformed/fixed cursors, retained-frontier withholding, one-byte
fragment caps, canonical byte offsets/provenance, and actual mutex contention.
Raw-active output supplies genuine source refs; pure observation must emit no raw
records or perform capacity waits. Root performs one concrete independent code/
oracle challenge after GREEN. Coordinate Debug Ninja through root; no sanitizer,
shared build configuration, broad source gate, commit, user session/provider, AFL
or artwork operation belongs to this lane without explicit coordination.

The permanent `ranges` and `ranges-raw` fixtures additionally advance 130 actual
8192-byte child emissions through owner acknowledgment, crossing the real 1MiB
tail eviction frontier. Their byte pages must clamp to the resident retained
prefix and retain a genuine within-native-chunk offset. This complements the
small fragmented-source test; neither fixture mutates private owner state.

The catalog limit counts metadata projections: eight catalog rows plus one
selected detail projection, at most nine. The selected map lookup is logarithmic
and does not consume catalog pagination. `examined_chunks` counts only source
chunks visited for copying; `seek_steps` separately counts deque binary-search
comparisons. There is no claim that a query visits at most eight map nodes in
its red-black-tree lookup. The owner cap is 256 resident jobs; the tail is at
most 1MiB of positive-size native chunks, so tree lookups and deque binary seek
have independent finite bounds. Zero byte/chunk/row budgets permit metadata-only
observation; the response says which budget prevented further output.

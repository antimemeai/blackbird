## Interaction and representation

The view keeps its command ID and output source interval through refresh, resize
and neighboring changes. A page identifies retained/received frontiers, resident
coverage and actual terminal/capture/custody state. Live versus settled, retained
terminal versus sealed capture, stale versus absent and empty versus unavailable
remain distinct. Only retained bytes appear as inspected output; publication
never drains/settles a command or starts another process.

The native collection/inspector has semantic previous/next, first/last, page and
focus actions. In inspection focus, arrows navigate the collection or detail;
Tab changes local focus. Escape returns to editing; Ctrl-O toggles the view.
Committed printable input and paste return to the existing literal editor,
without running bindings embedded in pasted bytes. Ctrl-C/quit and current PTY
foreground controls retain their current authority and priority. Opening or
changing selection never foregrounds, stops or reruns a command. The composer,
conversation scroll and route-local selection/reading anchor survive leave/return.
Wide geometry shows adjacent collection and detail; narrow geometry retains an
explicit return path. Tiny mode keeps the current terminal fallback and draft.

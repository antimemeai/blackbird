# Full-viewport application performance

The actual application now owns every physical terminal column, uses default-style blank-tail erase for routine frames, and clears/repaints recovery frames. This one matched Release round compares the committed pre-integration application `4b4113d18ba80ab1a23cea02f53a390c66bf7685` with the measured candidate. It is separate from the earlier native renderer policy competition.

All **120 processes / 960 endpoints completed**, with 30 trials per variant and geometry, zero failures, no discarded warmups/tails and no repeat. Source delivery is **7523da7ab8134e377cff1186e12fc71919d68ea5**. The measured native source is unchanged by delivery; [the exact mapping](delivered-source-delta.json) records two later test-only coordinate corrections, also preserved as [a patch](delivered-source-delta.patch).

Results are mixed. Typing p50 fell from 2.715 to 2.629 ms at 110x35 and 1.457 to 1.348 ms at 80x24. Resize recovery costs increased: 110x35 shrink p50 rose 3.044→5.745 ms and restore 3.794→5.557 ms; 80x24 restore rose 1.792→3.575 ms. Those p95 costs rose 4.287→8.734, 5.502→11.949 and 3.016→6.878 ms respectively. The new recovery path deliberately clears/repaints physical cells, but this observation does not isolate that source contribution from shared-host variation.

Wide paste p95 fell 298.117→47.349 ms while narrow paste p95 rose 47.111→54.990 ms. Small palette medians moved by at most 0.059 ms; some narrow palette tails worsened. These mixed deltas support retaining the correctness fix and tracking recovery cost and tails in the existing performance queue. They do not establish a blanket speedup or nonregression. [All sixteen endpoint rows, including maxima](DELTAS.md) and [raw samples](round/samples.jsonl) remain available. At 30 trials p99 equals the maximum.

The unchanged [historical observer](observer.py) and [external report](report.py) measured startup, unsubmitted text, 4 KiB bracketed paste, palette open/selection, resize draft, shrink and restore at 110x35 and 80x24. Each endpoint is parent PTY committed-text observation including scheduling/parsing, not GPU/display, provider/model or child-command latency. No inference turn was submitted. Graphics were disabled in this ordinary timing workload; graphics recovery has a separate selected correctness case.

The Linux baseline passed six selected native/custody/blocked/editor cases. The candidate passed those six plus the extended graphics case, then the actual-main full-physical oracle passed **18 phases on Ghostty and 18 on Alacritty**. Original summaries are [Ghostty](physical/ghostty-summary.json) and [Alacritty](physical/alacritty-summary.json). These independent cell/state checks establish last-column behavior; the historical observer's grid alone does not. This report adds no Mac result or whole-suite certification claim.

Both binaries used Clang 18.1.3, libstdc++ 13, C++20 Release, DebugOFF, no instrumentation and the same previously qualified Lua 5.4.8 library. [Profile](profile.json), [source manifests](candidate-source.json), build provenance and qualification logs preserve exact inputs. The source identity uses sorted path/content/byte-count/executable-bit records; manifests also retain original file modes.

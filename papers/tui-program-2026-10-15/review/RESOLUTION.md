# Integrated design challenge resolution

2026-10-15. One challenge with interaction, systems and BHI axes, followed by root
remediation and one direct consistency recheck. Original findings remain unchanged
in [INTERACTION](INTERACTION.md), [SYSTEMS](SYSTEMS.md) and [BHI](BHI.md).
No reviewer reviews another review. Five distinct issues were found; the text
insertion issue was independently raised on two axes.

| Finding | Resolution in integrated documents | Direct recheck |
| --- | --- | --- |
| P1 composition can dispatch effects through generic async API | Components now require a native non-forgeable phase at admission: composition/validation/preview only build and declare bounded owner-observation queries; identified handlers admit effects. No synchronous system/native-loader bypass in UI bindings. Doctrine/map/Unit2 agree. | Source-reading consistency: effectful remote fetch is not called a read-only view query; no admitted effect from failed candidate; future direct oracle requires rejection before owner admission. |
| P1 queued coordinates can retarget after frame change | Components capture acquisition-time geometry and resolved target in the owned event; later publication never reinterprets it. Unknown/transition association permits local inspection or refuses effects. Terminal physical-display limits remain explicit. Unit1 includes A→B reordering oracle. | Check captured event and dispatch use the same target/revision and no physical-frame identifier is invented for PTY reports. |
| P2 missing per-invocation bridge identity/ambiguous acknowledgment semantics | Components distinguish definition, trigger and invocation identities; retain accepted receipt/unknown independent of view; use domain reconciliation where supported; never automatically resubmit ambiguous delivery after reload. Distinct triggers remain distinct. Unit2 includes withheld-ack oracle. | Check no exactly-once remote guarantee or second durable operation ledger is claimed. |
| P2 protected insertion wording accidentally forbids current POWERWORDS | Doctrine and existing composer design distinguish literal draft insertion from deliberate Send's existing bare/POWERWORD grammar, including quoted/code matcher behavior. Unit1 preserves it. | Current callable-workflow contract remains the source of submission semantics; no paste or IME event dispatches merely by insertion. |
| P2 Context workbench absent from named implementation slices | Unit3 explicitly delivers Context/request/original repair using shared document/inspector/editor and current guarded operations. Unit6 context metrics link to it rather than substitute for it. | Next-request context timing, actual request inspection, original source references and deferred program activation remain distinct. |

These are design fixes and implementation oracles, not executed runtime results.
No component implementation, hardware trial, source test campaign or evaluator was
selected by the challenge. All requested view families have an explicit design and
current/partial/missing owner mapping. The final document/source/link/manifest
check is recorded in [the delivery check](../CHECKS.md).

processor or dictionary. Selection requires an explicit nonzero parent and an
active raw producer. A default direct adapter call stays unselected. Constructor
prepays its exact request plus52-byte maximum terminal. Request body is parentR

RawOperationBranch:u8, reached stage:u8, ErrorPresent:bool,[ErrorCode:u8,i64].
R is lane16/ordinal8; E is the16-byte existing envelope. No padding. It copies
native views into raw_emit, preserves errno, fences emission failures, and owns
no heap, callbacks, clock, serialization, subscriptions or metric arithmetic.
Fallible business bodies run inside the scope; child destruction precedes the
returned/thrown terminal. Destructor writes unresolved only when no outcome was
observed. Error, bad_alloc, length_error, standard/nonstandard throws stay distinct.
Each variable body has requestR,size_t length,unchanged bytes (E+32+N). Claim
before acquiring it, publish before any later parse/observer/configuration can
discard it. A standalone event claims before its business acquisition; held
terminal emission never waits. Checked frame arithmetic rejects an oversized
body before acquisition. No borrowing operation settlement credit.

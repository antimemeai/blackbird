## Shared composition and model ergonomics

Use owned native tagged values, immutable shared payloads, bounded ranges and checked identities at the C++/Lua boundary. Human gestures supply IDs/args to actual owners; model/Lua operations use the same owner without hidden current selection. New queue operations need equivalent structured inspection/mutation access when introduced, with version conflict and meaningful refusal. UI action receipt is not a second effect ledger. Per-invocation bridge identity survives view close/reload; reconcile only where actual owner supports it, otherwise unknown and no automatic replay.

Document/table/editor/status/async/return primitives should be reusable by conversation, participant direction, definition edit and context repair. This is expressive composition, not migration of every screen before useful delivery. Ordinary model source/context authoring stays autonomous. Shared services remain consumed/observed, never stopped by a main-turn/global UI button.

## Minimal observation, not producer analytics

Reuse existing raw input acquisition/handling, queue, worker dispatch, operation, provider, packet completion, original/source and owner transition events. If a missing relation prevents a claim, the owning source unit may add raw IDs, phase facts, offsets or clock samples only. Native producers do minimal capture/transport: no metric filtering, sampling, normalization, duration math, histogram, projection, aggregation, formatting or compression. Separate recorder preserves raw bytes; tertiary reader joins/derives latency/compensation summaries and declares missing coverage/clock mapping. No writer metric hooks for arbitrary programmable transforms. UI domain status is a native owner observation, not an illicit metric-derived progress percentage.

Task observations later distinguish input acquisition, control admission, owner result and visible-after-drain screen. Human mistaken resubmissions, wrong targets, place loss, compensatory checking, completion and subjective fluency require actual task observation, not audit-derived mind reading. This unit emits no new product instrumentation.
